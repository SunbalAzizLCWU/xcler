Work-Chat ist voller Menschen, die Router spielen: „kannst du SAP checken?“, paste, warten, ping. **Agent-natives Messaging** — Ando ist der Name in den Briefings dieser Woche — dreht das um. Sie nennen ein **Ziel im Thread**. Ein Agent mit Tools fährt einen **durablen Job**. Menschen nur bei Risiko.

Das fordert Slack/Teams als Default-OS der Arbeit. Es ersetzt sie nicht automatisch in einer GmbH mit Betriebsrat.

![Human-Chat versus Bot versus agent-nativer Thread](/blog/blog-agent-messaging-diagram.webp)

## Warum Slack-Bots dünn wirkten

Ein Slash-Command ist ein Formular. Kein Job-Memory, kein Warten auf Freigabe, kein Recht auf langsames ERP. Sie kopieren das Ergebnis weiter in den Channel. Agent-nativer Chat behandelt den **Thread als Ticket**: State, Artefakte, Pause bis ein Mensch per Card freigibt.

## Was Sie kopieren, wenn Sie bei Teams bleiben

- Ein Thread = eine Job-ID.
- Agentenidentität sichtbar (nicht „sieht aus wie Lisa“).
- Tools in der ersten Bot-Message.
- Freigabe als strukturierte Card.
- Transkript 30 Tage; **kein stilles Training** auf HR-Kanälen.

Das lässt sich mit n8n an Slack/Teams schrauben. Sie müssen das Unternehmen dieses Quartal nicht auf ein neues Chat-OS umziehen. Siehe [Workflow-Automatisierung](/leistungen/workflow-automatisierung).

## Risiken, weil „der Agent hier wohnt“

- **Oversharing**: der Agent liest einen Space, den er nicht darf. Tokens pro Space.
- **Betriebsrat** in Deutschland: Monitoring und automatisierte Leistung sind heikel. HR früh einbinden.
- **Shadow IT**: fünf Teams, fünf Ando-Klone. Ein Muster wählen.

## Praxis: Logistik-Exception-Channel

Statt @here bei fehllieferung startet ein Bot einen Job: Scan-Events, SMS-Entwurf, warten. Dispatcher tippt Approve. Der menschliche Chat hat drei Messages, nicht vierzig. Dieselbe Idee wie [Voice-Loops](/blog/sprachgesteuerte-multimodale-workflow-automatisierung), andere Oberfläche.

## FAQ

**Slack verlassen?**
Nein. Job-förmige Threads und einen Agenten mit Vertrag verlangen.

**Ist das ein Helpdesk?**
Es wird einer, wenn Sie den Ticket-Store überspringen. In Ihr ITSM spiegeln.

**DSGVO?**
Chat ist personenbezogen. EU-Hosting, AVV, Retention, kein Audio.
