## Musharraf Aziz's flagship architectures

- **Self-Healing RAG Pipeline (SHBRAG):** corrective RAG with a "confidence firewall" that grades retrieval, rewrites the query, re-retrieves or refuses instead of hallucinating. Built with Python, FastAPI, Qdrant, LangChain and Groq; the Groq grading step was reduced from about 1.2 s to about 180 ms.
- **VoiceRAG Core:** an ASGI WebSocket voice pipeline with Whisper speech-to-text, hybrid Pinecone + BM25 retrieval and Groq tokens streamed into text-to-speech — a sub-500 ms conversational loop with barge-in, used in production at 1,000+ daily interactions.
- **LLM Guardrail Gateway:** an API gateway that redacts PII/PHI from prompts (Microsoft Presidio, spaCy) and enforces output schemas.
- **Git Archaeologist MCP Server:** an open-source Model Context Protocol server for git repository analysis by AI agents.

His portfolio also lists AegisFlow, AuraNode (e-commerce on Next.js and Supabase) and dentl2 (dental clinic SaaS).
