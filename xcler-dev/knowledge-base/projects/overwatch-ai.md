## Overwatch AI overview

Overwatch AI is a security-focused AI command center built by XCLER that detects AI-powered scams across voice, image and text. It delivers multimodal threat intelligence with clear verdict dashboards for fast decisions. Overwatch AI is live.

## The challenge Overwatch AI solved

Scams increasingly combine synthetic voices, manipulated images and high-pressure text. Security teams needed one system that classifies multimodal threats quickly and explains the risk clearly.

## How XCLER built Overwatch AI

- **Frontend:** Next.js 14 and React command-center architecture; Tailwind CSS and Framer Motion; state-driven UI flow (Idle → Scanning → Verdict).
- **AI and detection:** Gemini 3.1 Flash multimodal models; system prompts built dynamically per media type; strict JSON schema enforcement so verdicts are machine-readable; outputs include threat level, authenticity score and manipulation tactics.
- **Backend:** Next.js serverless scan API handling text, URLs and file uploads (voice notes, screenshots).

## Overwatch AI delivery phases

1. Threat-intelligence product definition — triage from input to verdict in one guided interface.
2. Multimodal scan pipeline — media-aware prompting for audio, images, text and URLs.
3. Structured verdict intelligence — consistent fields for every analysis.
4. Cinematic operational interface — scanning animations and verdict dashboards.
